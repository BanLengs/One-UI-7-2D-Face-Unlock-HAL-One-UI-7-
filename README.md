# One-UI-7-2D-Face-Unlock-HAL-One-UI-7-
2D Face Unlock HAL built for third-party One UI 7 (Android 15) ports on Exynos 7420 Galaxy S6 / Note 5 series. Compatibility with other models or One UI versions is unverified and not guaranteed. Enables front-camera face unlock for lock screen, App Lock, and wake-to-unlock, using the stock "Settings > Biometrics > Face recognition" flow.
